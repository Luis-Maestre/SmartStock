# Runtime View

Durante la ejecución del sistema, los usuarios se autentican para acceder a las funcionalidades correspondientes a su rol. Las solicitudes son procesadas por el servidor, que actualiza la información del inventario, registra las operaciones en la base de datos y genera recomendaciones o reportes cuando es necesario.
