# Deployment View

SmartStock ERP se implementará como una aplicación web donde los usuarios accederán desde un navegador. El frontend desarrollado en React se comunicará con un servidor Node.js y Express, el cual administrará la lógica del negocio y almacenará la información en una base de datos MySQL.
