# Building Block View

La arquitectura de SmartStock ERP está organizada en módulos independientes que incluyen la gestión de usuarios, roles, productos, categorías, inventario, reportes, auditoría y el sistema inteligente de reposición. Cada módulo cumple una función específica y trabaja de forma integrada con los demás componentes del sistema.
