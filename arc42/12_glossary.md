# Glossary

Sistema Inteligente de Reposición

Motor de reglas que analiza el historial del inventario para generar alertas y recomendaciones de reposición

Dashboard

Pantalla principal donde se presentan indicadores, métricas y alertas

Movimiento

Registro de una entrada o salida de inventario

Stock Disponible

Cantidad actual de unidades almacenadas

Stock Mínimo

Cantidad mínima configurada para un producto

Proveedor

Empresa o persona que suministra mercancía

Auditoría

Registro de todas las acciones realizadas por los usuarios

Administrador

Usuario con permisos completos

Empleado

Usuario encargado de registrar operaciones del inventario
