# 2. Architecture Constraints

## Restricciones técnicas

- El sistema será desarrollado utilizando C#
- Se utilizará ASP.NET Core MVC
- La base de datos será SQL Server
- Entity Framework Core será el ORM
- Bootstrap, HTML5 y CSS3 será utilizado para la interfaz

## Restricciones organizacionales

- El proyecto será desarrollado por estudiantes
- El tiempo de desarrollo es inferior a tres meses
- Se utilizará GitHub para el trabajo colaborativo

## Restricciones del producto

- El sistema será una aplicación web
- No incluirá contabilidad
- No incluirá facturación electrónica
- No incluirá nómina
- No tendrá aplicación móvil

## Convenciones

- Arquitectura MVC
- Arquitectura en capas
- Uso del patrón Repository mediante Entity Framework
